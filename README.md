# Stomple Online

Онлайн-версия настольной игры Stomple: мобильный PWA, комнаты по коду, 2–6 игроков. Есть режим на одном телефоне.

## Как устроено

```
shared/engine.ts    правила игры — чистые функции, одинаковые на клиенте и сервере
shared/room.ts      логика комнаты (лобби, хозяин, ходы, обрывы, выход) — тоже без сети
shared/protocol.ts  формат сообщений клиент ↔ сервер
party/server.ts     Cloudflare Worker (partyserver + Durable Objects): принимает сообщения, рассылает снимок, хранит стейт сутки
src/                React-клиент: главная, лобби, экран игры, хот-сит
tests/              33 теста: правила, комната, сервер, экран игры
```

Ход отправляется на сервер, сервер проверяет его движком и рассылает всем новое состояние. Клиент анимирует разницу.

Сервер написан на `partyserver` — официальной библиотеке Cloudflare с API PartyKit, но деплоится в ваш собственный аккаунт Cloudflare (без общих лимитов partykit.dev).

## Запуск локально

```bash
npm install
npm run dev:party     # сервер комнат на localhost:1999
npm run dev           # клиент на localhost:5173 (в другом терминале)
```

Открой `http://localhost:5173`, создай комнату, открой ту же ссылку во второй вкладке или на телефоне в той же сети (`npm run dev -- --host`).

## Деплой — две команды

**1. Сервер комнат (Cloudflare Workers, бесплатный тариф)**

```bash
npx wrangler login     # один раз, откроется браузер Cloudflare
npm run deploy:party   # выдаст адрес вида stomple.<ник>.workers.dev
```

**2. Клиент (PWA)** — Cloudflare Pages, одной командой из терминала:

```bash
echo "VITE_PARTY_HOST=stomple.<ник>.workers.dev" > .env   # один раз
npm run deploy:web
```

Первый раз wrangler предложит создать проект `stomple` — соглашайся. Адрес будет `https://stomple.pages.dev`. HTTPS даётся автоматически — он нужен, чтобы PWA устанавливалась.

После деплоя: открой ссылку на телефоне → «Добавить на экран „Домой“».

## Правила, которые реализованы

- Поле 7×7, 49 шариков: по 7 каждого из 6 игровых цветов + 7 белых (ничьих).
- Первый ход: любой шарик на внешнем кольце, кроме своего цвета, ровно один.
- Далее: шаг на любой соседний шарик (8 направлений). Если рядом с ним есть шарики того же цвета — можно продолжать по ним в любую сторону, без возврата; остановиться можно где угодно.
- Прыжок: на любой свой шарик в любой точке поля, с тем же продолжением по своему цвету.
- Нельзя: на пустую лунку, на чужой стомпер, первым ходом на свой цвет.
- Игрок без ходов выбывает, когда до него доходит очередь. Последний получает 3 + по 1 за каждый белый и каждый свой шарик на поле.
- Игра до порога: 2 игрока — 40, 3 — 20, 4+ — 15. Хозяин может поменять в лобби.

## Сетевые правила

- Создатель комнаты — хозяин: начинает игру, жмёт «Следующий раунд», «Ещё партию», «В лобби». Если хозяин ушёл, роль переходит следующему на связи.
- Обрыв связи: игрок возвращается по ссылке на своё место. Если сейчас его ход — игра ждёт, хозяин видит таймер и кнопку «Пропустить».
- «Выйти из игры»: игрок выбывает из раунда, его очки замораживаются, порог не пересчитывается. Меньше двух активных — партия возвращается в лобби.
- Комната хранится сутки после ухода последнего участника.

## Голос и реакции

- **Реакции** — стикеры из `public/reactions/`, кнопка 😄 под полем. Летят всем сразу, появляются над чипом отправителя, в стейт не пишутся. Не чаще одного раза в 1,2 с.
- **Голосовой канал** — как в шутере: все в комнате слышат друг друга всегда, кнопка 🎤 включает/выключает только свой микрофон. WebRTC mesh, звук идёт напрямую между телефонами, сервер только знакомит участников. Кто говорит — подсвечивается рамкой чипа. Фоновая музыка приглушается, пока микрофон открыт.
- Если у кого-то из друзей голос «не доходит» (строгий NAT у оператора), добавьте TURN-сервер через `VITE_TURN_URL` / `VITE_TURN_USER` / `VITE_TURN_PASS` — см. `.env.example`.
- На iPhone микрофон в установленном PWA работает, пока приложение на переднем плане.

## Музыка (общий плеер)

1. Положи mp3/m4a в `public/music/`. Название берётся из имени файла: `Исполнитель - Название.mp3`.
2. `npm run tracks` — пересоберёт список (`src/tracks.json`); `npm run build` делает это сам.
3. `npm run deploy:web`.

Управляет плеером хозяин комнаты (⏮ ▶ ⏭, список по тапу на название), остальные слушают то же самое синхронно. Кнопка 🎵 в шапке выключает звук только у себя. Пока микрофон включён, музыка приглушается. Если треков нет — играет встроенная синтезированная мелодия.

Файлы попадают в сборку и кэш PWA — 3–6 треков нормально; больше лучше вынести на Cloudflare R2.
